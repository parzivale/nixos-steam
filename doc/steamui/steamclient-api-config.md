# steamui: SteamClient.* API surface and per-app configuration

Source: every `SteamClient.<Namespace>[.<Sub>].<Method>` reference in `root/steamui/*.js` (optional chaining `?.` included), plus the `"<Service>.<Method>#1"` names of the client-local protobuf services reached over `SteamClient.WebUITransport`. Linux client manifest 1791918634.

Only methods the UI actually references are listed. The native `SteamClient` object injected by steamwebhelper may expose more.

Totals: **800 distinct SteamClient methods in 65 namespaces**. About 280 are marked as configuration-related (setters, toggles, settings readers, storage).
